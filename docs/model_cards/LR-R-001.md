## Model overview and intended purpose

The legacy credit default logistic regression (LR-R-001) estimates the probability that a credit-card customer defaults next month and is used in credit decisions. It is implemented in R and predicts default.payment.next.month.

## Algorithm and methodology

The model is a logistic regression fitted with glm using a binomial family and logit link on 21 input features. ID, SEX and AGE are excluded from the predictors. Training uses a stratified 80% train / 20% test split, and a predicted probability above 0.35 is classed as default.
